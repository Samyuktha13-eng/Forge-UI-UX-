# Forge UI/UX

A polished, modern frontend recreation of the Talkiepedia website built as a responsive static site. The goal of this project was to preserve the original brand, content, and navigation while improving the overall user experience, information hierarchy, and visual presentation.

## What’s included

- A refined home page with a stronger hero section, featured episodes, about preview, and newsletter call-to-action
- A dedicated About page with a clearer story, mission, and values
- A redesigned Podcasts page featuring a team/gallery section, real Talkiepedia people, category-based episode filters, and real YouTube links
- A structured Contact page with contact details and a cleaner form layout
- Responsive navigation, modern card-based sections, and polished styling across all pages
- A lightweight AI-style recommendation experience for helping visitors discover relevant podcast episodes

## Tech stack

- HTML5
- CSS3
- JavaScript

No framework was required for this static front-end build.

## Project structure

- index.html — Home page
- about.html — About page
- podcasts.html — Podcasts experience
- contact.html — Contact page
- styles.css — Shared styling and layout
- script.js — Mobile navigation, gallery scroll, filters, and AI recommendation interactions

## How to run locally

You can preview the site directly by opening index.html in a browser.

For a local server, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
